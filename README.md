# 学生管理系统

一个使用 Python 标准库开发的命令行学生管理系统。项目支持学生信息的增删改查、成绩区间查询、班级统计以及 JSON 持久化存储。

## 功能

- 添加学生，并校验学号是否重复
- 校验年龄和成绩输入范围
- 按学号或姓名查询学生
- 按成绩区间查询学生
- 修改学生姓名、学号和成绩
- 按学号删除学生
- 显示全部学生信息
- 统计班级人数、平均分、最高分和最低分
- 使用 JSON 保存数据，重新启动后数据不会丢失

## 运行环境

- Python 3.10 或更高版本
- 无第三方依赖

## 运行项目

在项目根目录执行：

```powershell
python main.py
```

启动后可以通过菜单选择操作：

```text
1. 添加学生信息
2. 查询学生信息
3. 修改学生信息
4. 删除学生信息
5. 显示全部学生信息
6. 统计班级情况
0. 退出系统
```

## 数据格式

学生数据保存在 `students.json` 中。一条学生数据的格式如下：

```json
{
    "id": "001",
    "name": "小明",
    "age": 18,
    "score": 95.0
}
```

字段说明：

- `id`：学生学号，字符串类型且不能重复
- `name`：学生姓名
- `age`：年龄，范围为 1～100
- `score`：成绩，范围为 0～100

## 面向对象设计

`models.py` 中的 `Student` 类负责表示一名学生：

- `student_id` 和 `name` 保存学号与姓名
- 年龄和成绩使用封装属性保存
- `set_score()` 负责修改并校验成绩
- `to_dict()` 将对象转换成可保存到 JSON 的字典
- `from_dict()` 将 JSON 字典恢复成 `Student` 对象
- `__str__()` 返回学生信息的字符串表示

模块职责保持分离：

- `main.py` 只负责菜单和流程控制
- `service.py` 负责业务操作
- `storage.py` 负责文件读写
- `models.py` 负责学生数据模型

## 数据安全说明

- 添加、修改和删除学生后会立即保存数据
- 退出系统时会再次保存数据
- 数据文件不存在、JSON 损坏或数据结构异常时，程序会返回空学生列表，避免直接崩溃
